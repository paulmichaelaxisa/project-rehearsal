# Paste this into Grok → Build mode

Build a mobile-first web app called Project Rehearsal. Publish it to grok.me when it works. Enable SpaceXAI / Grok chat APIs inside the app so the simulation talks to Grok with no user-pasted API key.

Purpose: an AI flight simulator for delivery project managers. Skip any wizard. Two entry points only.

1) One-tap scenarios as big tappable cards:
- Hostile board pack (8 min). Cast: Helen CFO, Mark sponsor, Priya ops. They already think the forecast is fiction. Win: named decision and trade-off.
- Drive-by scope from a top account (8 min). Sales VP Dana, million-dollar language. Win: do not defend the roadmap; surface trade-offs.
- Stand-up of we'll (6 min). Alex, Jamie, Pat. Every action is we'll. Win: one name per action.
- Risk that never made the RAID (8 min). Pack is green, room is not. Win: name the risk without torching trust.
- We don't have resources (8 min). VP Eng. "No resources" means they fear missing their quarter. Win: ask what they are committed to before pitching.

2) Paste artefacts tab: large textarea for agenda, RAID, Slack, Jira sprint goal, last email. Button: Rehearse from this pack. Infer meeting, cast, and attacks from the text. Quote the artefacts.

Simulation screen: countdown timer, chat bubbles, composer pinned to the bottom (safe area), Say it + Debrief. Stakeholders stay in character, hidden motives, short turns, treat "we'll" as failure. On Debrief or timer zero output:
Trust /10, Delivery hold /10, Decision made, Named owner, What worked, Where it slipped, Next time tip, The line to steal.

Visual: dark #0b0d10, cards #171b22, accent #7c9cff, max-width 480px, 16px+ tap targets, system font. Headline: Fail in here. Not in steering.
